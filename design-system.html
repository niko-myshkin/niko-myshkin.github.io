  • A pill that opens into a card. The head folds away, so the open item reads as one paragraph with a bold lead.

The pill form of the accordion, after Apple's "Take a closer look". The block is a black plate; the phone is cut by its edge. Rules

How to change things

One place

Global values live in design-system.css

styles.css is for page composition only — structure that is not reused. A value written by hand anywhere is a bug.

New value

Add the token first, then use it

No token for what you need? Declare it on :root, then reference it. It shows up on this page by itself.

Dark theme

Override tokens, never components

Dark mode redefines values in :root[data-theme="dark"]. No component gets its own dark rule.

Cache

Bump ?v= in all four HTML files

Asset versions are hand-written, three per file. Miss one and the browser serves the old CSS.
