Explore by place, time, or chance.

  • Turn the year dial. Move between decades to hear how the music changes.

  • Tap the dice. Jump to a random place and era in one move.

More of Atlas

The thinking behind Atlas.

The live prototype lets you spin the globe, change decades, hear music previews and save discoveries during the session. There is no backend or full-track streaming.

I set the product direction, designed the interactions and tested the result. Claude Code and Codex helped write the code. The browser prototype uses HTML, CSS and JavaScript, with a three.js globe and a local demo profile.

The catalogue and playback paths were checked, including empty place × decade combinations. How people use Atlas and whether they return still need user testing.

Full tracks need music rights, and accounts need a backend. One possible route is to build the discovery experience inside a streaming service that already licenses its catalogue.
